# Introduction

Webhooks are a powerful way to listen to events that happen in your integration.
You can use webhooks to listen to events such as `payment.success` or `payment.refund` and handle them in your application.

In this section, you will find all the information you need to start using webhooks in your integration.

If it's your first time using webhooks, we recommend you to read the [🔊 Listening to Webhooks Guide](channel-manager/recipes/listening-to-webhooks) to get started.
