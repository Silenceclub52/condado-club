\---Fourvenues wants to be the best partner for your business, that's why we have created this documentation site to help you use our APIs. Here you'll find all the information about our actual APIs and the new ones that we are developing.

Now, there are two main APIs that you can use:
\- [Channel Manager API](/channel-manager/introduction/overview): This API allows you to manage the venues that are part of your marketplace or your own venues.
\- [Integrations API](/integrations/api-reference/introduction/overview): This API allows you to integrate your system with Fourvenues to get information about the events, scan tickets, and more but only for your own venues (not collaborators).
\- [Reseller API](/reseller/introduction/overview): This API is created for third-party resellers that want to do a secure resell.
